========================================
Backtest 策略清單 (2026-04 規劃 — 不動 pipeline 的驗證方法)
========================================

1. Brier Score + Calibration
   - Brier = mean((p_pred - y_actual)^2)，越低越好
   - Calibration: 依 ML home_win_prob 分 10 個 bucket，看每個 bucket
     的實際 home 勝率是否貼近 bucket 中位數
   - 目的: 比命中率更靈敏地揭露「信心過高 / 過低」的模型
   - 資料需求: 現有 probs_ml + y_ml

2. EV-Tiered ROI (Expected Value 門檻篩選)
   - 現在鑽石條件: 信心或 edge 高
   - 新條件: EV = p * (dec_odds - 1) - (1 - p) > threshold 才下注
   - 分層: EV < 0, 0-2%, 2-5%, 5-10%, >10%
   - 若 ROI 隨 EV 層遞增 → 模型真的在辨識 value
   - 資料需求: probs_ml, ml_h, ml_a, y_ml

3. Spread-Bucketed ROI
   - 依 |spread| 分組: 0-3 / 3-6 / 6-10 / 10+
   - 各自算 value/elite ROI
   - 找出模型真正有 edge 的盤口區段 → UI 上把其他區段標灰
   - 資料需求: spreads, probs_ml/probs_ats, margins

4. Power Rating Stability (長期項目, 延後)
   - 跨天比對 implied rating 平滑度
   - 需要跨 snapshot 的預測紀錄 — 這個 repo 還沒有
   - 列在 roadmap，等 CLV pipeline 先做出 snapshot 機制再回來

驗證腳本: scripts/backtest_strategies.py
