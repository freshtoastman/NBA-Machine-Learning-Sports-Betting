## 每日紀錄

### 2026-10-01 — 賽季復盤（v2）

**做了什麼**：用 git 歷史重建 4/10–6/13 每場比賽的賽前快照並評分（`scripts/audit_live_record.py`）；用前一天數據表重建 2024-25／2025-26 資料集，拿正式模型重新評分（`scripts/audit_feature_leak.py`）。重建的洩漏版資料集與正式 `dataset.sqlite` 重疊的 1,862 列逐欄完全相同，驗證了比對方式。

**發現**：
1. 同日數據洩漏：2025-26 的 TeamData 有 497/536、AdvancedTeamData 有 486/528 張「當天表」已含當天比賽。去除洩漏後，2025-26 value+過濾從 24-2（92.3%）降到 **24-9（72.7%）**，ML 從 70.4% 降到 **66.8%**。
2. 實戰賽前紀錄（n=119）：ML 48-30（61.5%）、季後賽 GOLD+SILVER 每場主訊號 32-27（54.2%）、大小分 46.2%。
3. 有 44 條賽前顯示的訊號在賽後從檔案中消失（15 中、29 錯），追蹤器的 67.6% 因此被灌水。
4. 選表 bug：`odds_2025-26`（殘缺，562 場）在 `MAX(Date)` 同日時勝出，dataset 少約 760 場；總決賽期間的球隊輪廓只用 43 場歷史計算。
5. 值得保留：主場 value 注無洩漏兩季 16-4；10–11 月 value 注 28-12，12–1 月只有 14-14；ML 模型在 70–80% 信心區間偏保守（預測 74%、實際 83%）。

**決定**：6/23 回顧的 85%／86.7%／67.6% 全部作廢，改以第 8 節的定義衡量（賽前凍結紀錄 ≥30 注且 ≥85% 才算達標）。記憶檔中的相關宣稱已更正。

**下一步（10/2）**：P0 選表邏輯統一 → 重建 dataset → 確認 2025-26 約 1,320 場、`season_stats` 重算。另外追蹤 Duren 的 qualifying offer 結果。
